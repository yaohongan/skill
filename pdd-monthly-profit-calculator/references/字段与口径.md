# 字段与核算口径

## 成本表

必需字段：

| 含义 | 可识别字段名 |
|---|---|
| 商品 ID | `商品id`、`商品ID`、`商品Id`、`商品编号` |
| 单件总成本 | `总成本` |

商品 ID 会去除首尾空格、制表符和 Excel 数字尾部的 `.0`。总成本按数值读取。

## 订单表

必需字段：`订单号`、`订单状态`、`售后状态`、`订单成交时间`、`商品id`、`商家实收金额(元)`、`商品数量(件)`。

可选追溯字段：`商品`、`商品规格`。存在时写入客户核对版明细。

## 状态排除

- 订单状态包含：取消、待付款、未付款、退款、退货。
- 售后状态包含：退款中、退款成功、退货中、退货成功、售后处理中、处理中、待买家退货、待商家处理。
- `无售后或售后取消`属于有效状态，不排除。

## 日期与投流

- 日期范围以投流截图为准，包含起止日期当天。
- 截图中的“总花费(元)”作为全店投流费用扣除。
- `1.31万`换算为`13,100元`；因为截图可能四舍五入，报告中必须标为近似值，并提供黄色可编辑金额格。

## 暂算口径

成本表没有对应商品 ID 时，仅汇总该商品的订单行数、商品数量和商家实收，不计算其成本与毛利。已匹配部分照常计算，整体结果标记为“暂算”。补齐成本后重新运行即可得到完整核算。
