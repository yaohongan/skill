# 拼多多月度盈亏字段与匹配规则

## 订单字段别名

| 标准字段 | 可识别字段 |
|---|---|
| 订单号 | 订单号、订单编号、主订单号 |
| 商品ID | 商品id、商品ID、商品编号 |
| 商品名称 | 商品、商品名称、商品标题 |
| 商品规格 | 商品规格、规格名称、SKU名称、sku名称 |
| 商品数量 | 商品数量(件)、商品数量、数量、购买数量 |
| 商家实收 | 商家实收金额(元)、商家实收金额、商家实收 |
| 支付时间 | 支付时间、订单支付时间、付款时间 |
| 订单成交时间 | 订单成交时间、成交时间、下单时间 |
| 订单状态 | 订单状态、交易状态 |
| 售后状态 | 售后状态、退款状态 |

支付时间优先于订单成交时间。缺少订单号、商品规格、商品数量、商家实收、订单状态和两类时间字段时暂停。

## 成本字段别名

| 标准字段 | 可识别字段 |
|---|---|
| SKU名称 | sku名称、SKU名称、sku、商品规格、规格名称 |
| 口味 | 口味、口味说明 |
| 重量 | 重量、克重、规格重量 |
| 商品成本 | 成本、商品成本 |
| 运费 | 运费、物流成本 |
| 总成本 | 总成本、单件总成本 |

优先采用总成本。没有总成本但同时存在商品成本和运费时，按两者之和计算单件总成本。

## 订单排除规则

- 订单状态包含退款成功、已取消、订单取消、交易关闭或订单关闭：剔除为“退款/取消”。
- 售后状态包含退款成功：剔除为“退款/取消”。
- 售后状态包含处理中：剔除为“售后处理中”。
- “无售后或售后取消”不属于剔除状态。

## SKU标准化

允许的安全标准化：

- 去除首尾和重复空白。
- 统一全角与半角括号、逗号、加号和横线。
- 去除订单规格开头的父规格前缀，例如 `400g,`，但保留后面的实际SKU克重。
- 统一大小写。

不得删除或忽略：

- 品类词，如南瓜子、西瓜子、葵花子。
- 口味词，如原味、陈皮、奶油、椒盐。
- 克重、袋数和组合关系。

## 匹配优先级

1. SKU名称安全标准化后完全一致。
2. 品类、口味和实际总克重唯一一致。
3. 候选成本全部相同，可采用其中一条并注明“同成本匹配”。
4. 仅在品类、口味和克重已经一致时，使用营销标签进行高置信区分；最高候选必须达到阈值并明显领先第二候选。
5. 候选成本冲突、分差不足或没有候选时，标记未匹配并暂停。

营销标签只用于同品类、同口味、同克重候选内部区分，例如口碑/复购、双味/组合、囤货/更省、实惠、量贩、尝鲜/试吃、追剧/宅家。不得跨品类或跨克重匹配。

## 克重识别

支持 `g`、克、`kg`、千克、公斤和斤。组合规格中：

- `原味+陈皮各400克` 按800克。
- `原味+陈皮各1袋共800g` 按总重800克，不重复相加。
- 同一描述明确列出多个克重并用加号连接时，按合计克重。

## 暂停条件

- 截图日期或推广总花费无法可靠识别。
- 订单关键字段缺失或金额、数量、时间无法解析。
- 成本表没有可用总成本。
- 同一标准化SKU存在不同总成本。
- SKU无匹配或候选成本冲突。

暂停时只输出问题和去重后的未匹配SKU清单，不输出正式全店盈亏。
