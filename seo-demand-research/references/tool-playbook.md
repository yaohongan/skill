# Tool Playbook

Use current data. Dates matter.

## Google SERP

Use for every serious candidate.

Record:

- exact query and country/language assumption;
- top 5-10 results;
- page type;
- visible ads or AI overview;
- snippets and search intent;
- competitor domain age/traffic if browser extensions show it.

Manual SERP judgment can overrule KD.

## Ahrefs Keyword Difficulty

Use for:

- KD;
- estimated followed backlinks needed;
- visible SERP overview;
- DR, UR, backlinks, domains, traffic, keywords when shown.

Interpretation:

- KD 0-20: inspect SERP; may be good.
- KD 21-40: possible if SERP is weak or long-tail.
- KD 41-60: usually not cold-start unless there is a strong niche gap.
- KD 60+: avoid for first wedge.

If Ahrefs says many referring domains are needed, treat the keyword as harder even if volume looks attractive.

## Semrush

Use for:

- country-specific volume;
- global volume;
- KD%;
- CPC;
- intent label;
- trend chart;
- keyword variations and questions.

Prefer keywords with action/commercial or mixed informational-tool intent.

## Similarweb

Use for competitor validation:

- monthly visits;
- geography;
- traffic channels;
- search dependency;
- competitor overlap.

If top competitors have very high visits and strong product-market fit, do not call the keyword easy.

## Google Trends

Use for:

- new terms;
- seasonality;
- rising breakouts;
- comparing synonyms.

Do not rely on Trends alone. Pair with SERP and keyword tools.

## Local Browser / Tabbit

When user asks to use the local browser:

- use existing logged-in sessions for SEO tools;
- inspect competitor products directly;
- avoid purchases, account setting changes, and production mutations unless explicitly asked;
- record observations in the final report.
