# Research SOP

## 1. Seed Expansion

Start from the user idea and expand across these axes:

- Input format: PDF, notes, transcript, image, URL, CSV, audio.
- Output format: flashcards, quiz, summary, worksheet, Anki deck, Quizlet set, study guide.
- User role: student, teacher, nurse, law student, med student, language learner.
- Job-to-be-done: convert, generate, extract, practice, memorize, export, review.
- Platform: Anki, Quizlet, Notion, Google Docs, YouTube, Canvas, Moodle.
- Modifier: free, AI, online, automatic, from PDF, no signup, for exam.

Create 30-100 raw candidates before filtering.

## 2. First Filter

Remove keywords that are:

- too broad for a new site;
- purely informational with no tool intent;
- dominated by entrenched brands;
- unrelated to a monetizable workflow;
- impossible to build a useful MVP for.

Keep candidates with:

- clear action intent;
- visible search demand or rising trend;
- low-to-medium SERP quality;
- weak or generic competitors;
- a buildable feature surface.

## 3. SERP Validation

For each serious candidate, inspect Google manually.

Record:

- top ranking URLs and page titles;
- domain age if visible;
- monthly visits if visible;
- Ahrefs KD and backlink estimate if available;
- Semrush volume, KD, CPC, and intent if available;
- whether top pages are tools, blogs, directories, docs, Reddit, videos, or app pages;
- whether the top result fully satisfies the searcher.

## 4. Competitor Product Review

For direct competitors, test the product if possible.

Record:

- first screen value proposition;
- whether the tool is usable before signup;
- input limits;
- output quality;
- editing and export support;
- pricing and paywall moment;
- speed and errors;
- SEO page structure;
- trust signals;
- weakness a small competitor can exploit.

## 5. Opportunity Decision

Choose a wedge only when these are true:

- user intent is narrow and urgent;
- the page can rank through focused SEO and backlinks;
- the MVP can deliver the promised result;
- competitors have visible gaps;
- pricing can cover API costs;
- content/supporting pages can form a topical cluster.

Reject or postpone if:

- Ahrefs indicates 50+ KD and many followed domains are required;
- top 3 results are old, high-traffic, high-authority product pages;
- user intent is already fully satisfied;
- there is no differentiated angle;
- product cost exceeds likely willingness to pay.

## 6. Final Deliverable

Always end with:

- recommended direction;
- ranked keyword table;
- why the winner beats alternatives;
- competitor gaps;
- MVP scope;
- SEO page map;
- validation risks;
- next concrete tasks.
